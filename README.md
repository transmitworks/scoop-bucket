# KnockPort Scoop bucket

Install [KnockPort](https://knockport.com) on Windows with Scoop:

```
scoop bucket add transmitworks https://github.com/transmitworks/scoop-bucket
scoop install knockport
```

Update later with `scoop update knockport`.

KnockPort is source-available (FSL-1.1-ALv2). The Windows installer is not
code-signed yet, so SmartScreen may show an "unknown publisher" notice on first
run.
